# Local CI Evidence Contract (Advisory Only)

This slice defines the version 1 local-evidence data contract. The companion bridge now executes catalogued checks in a disposable detached worktree and can publish an explicitly confirmed advisory comment. The contract itself remains side-effect free and does not run Actions or change a release control.

Every record binds the GitHub host, authenticated login, `owner/repository`, PR number, and exact lower-case 40-character head SHA. Evidence accepts only a private trusted-discovery capsule; caller-provided identity fields and caller-created lookalike objects cannot create evidence. The bridge obtains this binding through the active `gh` account and repository, then runs only static catalog entries with bounded, redacted output. The model exposes only `pass`, `fail`, and `blocked`; missing or unprovable information must be `blocked`, never `pass`.

Evidence is explicitly `source=local`, `advisory=true`, `githubActions=false`, and `receipt=false`. It does not satisfy required checks, change merge or release eligibility, or replace hosted provenance. DeployLite remains Alpha, and PR #85 / the Platform Release Baseline chain are outside this bridge.

`evidence.mjs` provides deterministic sorted-key serialization, SHA-256 hashing, bounded excerpts, secret/path redaction primitives, and rejects secret-bearing argv before serialization or hashing. The schema enforces the discovery marker and rejects common secret-bearing argv shapes; the model applies the complete semantic guard, including known secret values. Publication uses only the GitHub Issue-comment API after explicit confirmation and rechecks the bound identity and SHA. Evidence remains `source=local`, `advisory=true`, `githubActions=false`, and `receipt=false`: it is never a required check, merge or release gate, or hosted provenance. To roll back this slice, remove only this schema, model, tests, bridge, and document; no gate, receipt, PR, account, or release state needs restoration.
